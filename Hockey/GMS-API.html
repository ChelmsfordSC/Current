Overview

GMS-API is a small JSON API that mirrors the fixtures, results and league standings for Chelmsford Sports Club's hockey teams. It's built and run by the club's IT volunteers, and it's free for anyone connected to the club to use — for a display screen in the clubhouse, a personal project, or anything else.

Base URL: https://gms-api.chelmsfordsc.org.uk

Every endpoint below is a GET request over HTTPS and returns JSON. There's nothing to install and no SDK — any language or tool that can make an HTTPS request and read JSON will work, including a browser's own fetch().

Getting an API Key

Every request needs an API key. Email it@chelmsfordsc.org.uk with a line or two about what you're building, and we'll send you a key. There's no cost and no formal approval process — this is just so we know who's using it and can let you know if anything changes.

Using your key

Send it on every request as an X-API-Key header:

X-API-Key: YOUR_API_KEY
Keep your key out of any code you publish publicly (a public GitHub repo, a client-side script anyone can view the source of, etc.). If you think a key has leaked, email us and we'll issue you a new one.

GET /api/today

Returns fixtures and results scheduled for today only, so you don't have to filter the full fixture list yourself for a simple "what's on today" display.

GET https://gms-api.chelmsfordsc.org.uk/api/today

No parameters.

Example request

# curl
curl -H "X-API-Key: YOUR_API_KEY" \
  https://gms-api.chelmsfordsc.org.uk/api/today

Example response

{
  "fixtures": [
    { /* same shape as /api/fixtures below */ }
  ]
}

Same field shape as /api/fixtures below, just filtered down to today's date — an empty array simply means nothing's on today.

GET /api/fixtures

Returns every known fixture and result across Chelmsford's hockey teams and the competitions they play in — past, present and future.

GET https://gms-api.chelmsfordsc.org.uk/api/fixtures?team=47e1e6e9-120c-4185-ad68-be7b70b76eac&comp_id=e28a25be-e7df-41b2-a923-a5c2921c0ca6&from=2026-09-01&to=2026-12-31

All four query parameters are optional and can be combined — drop them all to get everything:

ParameterDescription
teamA club_team_id (see /api/teams) — only fixtures involving that Chelmsford team.
comp_idA competition ID (see /api/leagues) — only fixtures in that competition.
from / toISO dates (YYYY-MM-DD), inclusive — filters on the fixture's date.

Example request

# curl -- one team, from today onward
curl -H "X-API-Key: YOUR_API_KEY" \
  "https://gms-api.chelmsfordsc.org.uk/api/fixtures?team=47e1e6e9-120c-4185-ad68-be7b70b76eac&from=2026-09-18"

Example response

{
  "fixtures": [
    {
      "fixture_id": "19_sep_2026_upminster_3_chelmsford_4",
      "comp_id": "e28a25be-e7df-41b2-a923-a5c2921c0ca6",
      "home_team_name": "Upminster 3",
      "away_team_name": "Chelmsford 4",
      "fixture_date": "19 Sep 2026",
      "fixture_date_iso": "2026-09-19",
      "fixture_time": "11:30",
      "status": "scheduled",
      "home_score": null,
      "away_score": null,
      "scorers": null,
      "venue_name": "Coopers Company & Coborn School",
      "venue_url": "https://www.google.com/maps/search/?api=1&query=Coopers+Company+%26+Coborn+School",
      "club_team_id": "47e1e6e9-120c-4185-ad68-be7b70b76eac",
      "club_side": "away",
      "last_updated": "2026-09-17T17:39:41.899Z"
    }
  ]
}

Each fixture carries its own fixture_id (a stable ID derived from its date and the two team names — use it with /api/fixtures/:id), both a display date (fixture_date) and a sortable one (fixture_date_iso, also what the from/to filters above compare against), and a status that's "scheduled" until the match is played and "completed" afterwards, at which point home_score/away_score are filled in. club_team_id/club_side are only set on the side that's actually one of Chelmsford's own teams.

GET /api/fixtures/:id

Returns a single fixture by its fixture_id — the same ID shown in the /api/fixtures list above.

GET https://gms-api.chelmsfordsc.org.uk/api/fixtures/19_sep_2026_upminster_3_chelmsford_4

Example request

# curl
curl -H "X-API-Key: YOUR_API_KEY" \
  https://gms-api.chelmsfordsc.org.uk/api/fixtures/19_sep_2026_upminster_3_chelmsford_4

{
  "fixture_id": "12_sep_2026_chelmsford_5_tower_hamlets_1",
  "comp_id": "255273c5-c270-4304-b396-cc1b911a5754",
  "home_team_name": "Chelmsford 5 (F)",
  "away_team_name": "Tower Hamlets 1",
  "fixture_date": "12 Sep 2026",
  "fixture_date_iso": "2026-09-12",
  "fixture_time": null,
  "status": "completed",
  "home_score": 5,
  "away_score": 3,
  "scorers": null,
  "venue_name": "Coopers Company & Coborn School",
  "venue_url": "https://www.google.com/maps/search/?api=1&query=Coopers+Company+%26+Coborn+School",

GET /api/teams

Lists Chelmsford's own hockey teams as the API currently knows them, along with the club_team_id used to filter /api/fixtures by team. Only teams the pipeline has actually seen play are listed — a brand new team won't appear until its first fixture has been picked up.

GET https://gms-api.chelmsfordsc.org.uk/api/teams

No parameters.

Example request

# curl
curl -H "X-API-Key: YOUR_API_KEY" \
  https://gms-api.chelmsfordsc.org.uk/api/teams

Example response

{
  "teams": [
    {
      "club_team_id": "47e1e6e9-120c-4185-ad68-be7b70b76eac",
      "team_name": "Chelmsford 4",
      "fixture_count": 22,
      "last_seen": "2027-03-20"
    },
    {
      "club_team_id": "09083ed3-cd42-4c8a-9cd1-0813729badb8",
      "team_name": "Chelmsford 5 (F)",
      "fixture_count": 18,
      "last_seen": "2027-03-06"
    }
  ]
}

team_name is the team name as most recently seen (it may or may not carry a gender suffix like "(F)", depending on which league page it was last seen on); last_seen is the latest fixture_date_iso we have for that team, played or upcoming.

GET /api/leagues

Self-serve lookup for competition IDs — no need to email us for a comp_id any more. Only lists competitions one of Chelmsford's own teams is actually registered in, and grows automatically as new teams/seasons are picked up.

GET https://gms-api.chelmsfordsc.org.uk/api/leagues?search=Women

The optional search parameter does a case-insensitive substring match on the competition name — leave it off to list everything.

Example request

# curl
curl -H "X-API-Key: YOUR_API_KEY" \
  "https://gms-api.chelmsfordsc.org.uk/api/leagues?search=Women"

Example response

{
  "leagues": [
    {
      "comp_id": "255273c5-c270-4304-b396-cc1b911a5754",
      "name": "East Women's Division 2 South East",
      "season": "2026-2027",
      "gender": "F"
    },
    {
      "comp_id": "b69e5afd-30e5-484c-b8a9-f5ca0cf010c0",
      "name": "East Women's Premier Division",
      "season": "2026-2027",
      "gender": "F"
    }
  ]
}

Use a comp_id from here with /api/leagues/:comp_id, /api/standings, or as ?comp_id= on /api/fixtures.

GET /api/leagues/:comp_id

Direct lookup for a single competition once you already have its comp_id cached, rather than searching by name every time.

GET https://gms-api.chelmsfordsc.org.uk/api/leagues/255273c5-c270-4304-b396-cc1b911a5754

Example request

# curl
curl -H "X-API-Key: YOUR_API_KEY" \
  https://gms-api.chelmsfordsc.org.uk/api/leagues/255273c5-c270-4304-b396-cc1b911a5754

Example response

{
  "comp_id": "255273c5-c270-4304-b396-cc1b911a5754",
  "name": "East Women's Division 2 South East",
  "season": "2026-2027",
  "gender": "F"
}

If no competition matches the given comp_id, you'll get a 404 instead: {"error": "Not found"}.

GET /api/standings

Returns the league table for a single competition.

GET https://gms-api.chelmsfordsc.org.uk/api/standings?comp_id=255273c5-c270-4304-b396-cc1b911a5754

comp_id is required — see /api/leagues to look one up by name.

Example request

# curl
curl -H "X-API-Key: YOUR_API_KEY" \
  "https://gms-api.chelmsfordsc.org.uk/api/standings?comp_id=255273c5-c270-4304-b396-cc1b911a5754"

Example response

{
  "standings": [
    {
      "team_name": "Chelmsford 4",
      "position": 1,
      "played": 4,
      "won": 3,
      "drawn": 1,
      "lost": 0,
      "goals_for": 12,
      "goals_against": 3,
      "goal_difference": 9,
      "points": 10
    }
  ]
}

One entry per team in the competition, ordered by league position. The response is always an object with a standings array — empty ({"standings": []}) if there's no data for that comp_id yet, rather than an error.

GET /api/status

A simple health-check — confirms the API is up and returns the single most recent scrape log entry, so you can see when the underlying data was last refreshed and whether that refresh succeeded.

GET https://gms-api.chelmsfordsc.org.uk/api/status

No parameters.

Example request

# curl
curl -H "X-API-Key: YOUR_API_KEY" \
  https://gms-api.chelmsfordsc.org.uk/api/status

Example response

{
  "last_scrape": {
    "id": 1657,
    "show_type": "matchdays",
    "club_id": null,
    "comp_id": "b69e5afd-30e5-484c-b8a9-f5ca0cf010c0",
    "status": "success",
    "message": "...",
    "run_at": "2026-09-18T18:24:41.178Z"
  }
}

status on the inner object is one of "success", "empty" (ran fine, nothing new), "skipped" (e.g. a stage lock was already held), or "error".

GET /api/status/history

Like /api/status, but returns a run of recent scrape log entries instead of just the latest one — handy for spotting a pattern (e.g. a cluster of errors) without needing direct database access.

GET https://gms-api.chelmsfordsc.org.uk/api/status/history?limit=10

The optional limit parameter controls how many entries come back, most recent first — defaults to 20, capped at 100.

Example request

# curl
curl -H "X-API-Key: YOUR_API_KEY" \
  "https://gms-api.chelmsfordsc.org.uk/api/status/history?limit=10"

Example response

{
  "history": [
    { /* same shape as the inner object in /api/status above */ },
    { /* ... */ }
  ]
}

Errors

Errors come back as JSON with a normal HTTP status code:

StatusMeaningExample body
401 Missing or incorrect X-API-Key header. {"error": "Unauthorized"}
429unverified Too many requests in a short space of time — see Rate Limits. (Confirmed correct by code inspection; we haven't yet actually tripped this limit against a real key to see it live.) {"error": "Too many requests"}

Rate Limits

This API runs on a free hosting tier, so there's a limit on how many requests it accepts from any one key or address in a short period. Normal use — a page that refreshes every so often, a script that checks in occasionally — will never come close to it.

If you're building something that needs to call the API very frequently (many times a minute, for lots of users), please email it@chelmsfordsc.org.uk first so we can make sure it'll work smoothly for everyone.

Support

Questions, API key requests, competition IDs, or something not working as documented — email it@chelmsfordsc.org.uk and we'll help out.
