Overview

GMS-API is a small JSON API that mirrors the fixtures, results and league standings for Chelmsford Sports Club's hockey teams. It's built and run by the club's IT volunteers, and it's free for anyone connected to the club to use — for a display screen in the clubhouse, a personal project, or anything else.

Base URL: https://gms-api.chelmsfordsc.org.uk

Every endpoint below is a GET request over HTTPS and returns JSON. There's nothing to install and no SDK — any language or tool that can make an HTTPS request and read JSON will work, including a browser's own fetch().

Getting an API Key

Every request needs an API key. Email it@chelmsfordsc.org.uk with a line or two about what you're building, and we'll send you a key. There's no cost and no formal approval process — this is just so we know who's using it and can let you know if anything changes.

Using your key

Send it on every request as an X-API-Key header:

X-API-Key: YOUR_API_KEY
Keep your key out of any code you publish publicly (a public GitHub repo, a client-side script anyone can view the source of, etc.). If you think a key has leaked, email us and we'll issue you a new one.

GET /api/today

GET /api/today

Returns fixtures and results scheduled for today only. Useful for a "what's on today" display without having to filter the full fixture list yourself.

Parameters

None.

Example request

# curl
curl -H "X-API-Key: YOUR_API_KEY" \
  https://gms-api.chelmsfordsc.org.uk/api/today
// JavaScript (fetch)
const res = await fetch('https://gms-api.chelmsfordsc.org.uk/api/today', {
  headers: { 'X-API-Key': 'YOUR_API_KEY' }
});
const data = await res.json();

Example response

{
  "fixtures": [
    { /* same shape as /api/fixtures below */ }
  ]
}

Same field shape as /api/fixtures below, filtered down to just today's date — an empty array simply means nothing's on today.

GET /api/fixtures

GET /api/fixtures

Returns every known fixture and result across Chelmsford's hockey teams and the competitions they play in — past, present and future.

Parameters

None.

Example request

# curl
curl -H "X-API-Key: YOUR_API_KEY" \
  https://gms-api.chelmsfordsc.org.uk/api/fixtures
// JavaScript (fetch)
const res = await fetch('https://gms-api.chelmsfordsc.org.uk/api/fixtures', {
  headers: { 'X-API-Key': 'YOUR_API_KEY' }
});
const data = await res.json();

Example response

{
  "fixtures": [
    {
      "fixture_id": "19_sep_2026_11_30_upminster_3_chelmsford_4",
      "comp_id": "e28a25be-e7df-41b2-a923-a5c2921c0ca6",
      "home_team_name": "Upminster 3",
      "away_team_name": "Chelmsford 4",
      "fixture_date": "19 Sep 2026",
      "fixture_time": "11:30",
      "status": "scheduled",
      "home_score": null,
      "away_score": null,
      "scorers": null,
      "venue_name": "Coopers Company & Coborn School",
      "venue_url": "https://www.google.com/maps/search/?api=1&query=Coopers+Company+%26+Coborn+School",
      "club_team_id": "47e1e6e9-120c-4185-ad68-be7b70b76eac",
      "club_side": "away",
      "last_updated": "2026-09-17T17:39:41.899Z"
    }
  ]
}

Field reference

FieldDescription
fixture_idStable unique ID for this fixture. Use it with /api/fixtures/:id.
comp_idID of the competition this fixture belongs to, or null if not yet known. See /api/standings.
home_team_name / away_team_nameTeam names as published by the league.
fixture_date / fixture_timeDate and kick-off time as text, e.g. "19 Sep 2026", "11:30" (or "TBC").
statusCurrently always "scheduled" — result status may be added once matches have been played.
home_score / away_scoreFinal score, or null if the match hasn't been played yet.
scorersGoalscorer information, or null if not available.
venue_name / venue_urlWhere it's being played, with a link to a map where one is known.
club_team_id / club_sideOnly populated when Chelmsford is playing in this fixture — which of our teams it is, and whether we're "home" or "away".
last_updatedWhen this row was last refreshed from the league's own system, as an ISO timestamp.

Not found

If no fixture matches the given id, the API returns a 404:

{
  "error": "Not found"
}

GET /api/leagues

GET /api/leagues

Looks up the leagues (competitions) Chelmsford's teams play in, along with the comp_id each one needs for /api/standings. Use this instead of emailing us to ask for a comp_id.

Parameters

NameInDescription
searchQuery stringOptional. Filters by league name, case-insensitive, e.g. ?search=Division 3. Omit it to list everything.

Example request

# curl
curl -H "X-API-Key: YOUR_API_KEY" \
  "https://gms-api.chelmsfordsc.org.uk/api/leagues?search=Division%203"
// JavaScript (fetch)
const res = await fetch('https://gms-api.chelmsfordsc.org.uk/api/leagues?search=Division%203', {
  headers: { 'X-API-Key': 'YOUR_API_KEY' }
});
const data = await res.json();

Example response

{
  "leagues": [
    {
      "comp_id": "e28a25be-e7df-41b2-a923-a5c2921c0ca6",
      "name": "East Open - Men's Division 3 South East",
      "season": "2026-2027",
      "gender": "M"
    }
  ]
}

Field reference

FieldDescription
comp_idPass this straight into /api/standings?comp_id=.
nameLeague name as published by England Hockey.
seasonSeason this league ID applies to, e.g. "2026-2027". IDs are usually reissued each season.
gender"M" or "F".

This list only covers leagues one of Chelmsford's own teams is actually registered in this season — it grows automatically as new fixtures are scraped, so a brand-new team or competition may take a little while to appear. If you need a league that isn't showing up yet, email it@chelmsfordsc.org.uk.

GET /api/status

GET /api/status

Reports on the most recent scrape run against the league system, so you can see when the underlying data was last refreshed (and whether that refresh succeeded) before relying on the other endpoints.

Parameters

None.

Example request

# curl
curl -H "X-API-Key: YOUR_API_KEY" \
  https://gms-api.chelmsfordsc.org.uk/api/status

Example response

{
  "last_scrape": {
    "id": 814,
    "show_type": "teams",
    "club_id": "e9ba26d3-7e18-4772-abb0-584e887c9d38",
    "comp_id": null,
    "status": "success",
    "message": "{\"html\":\"...raw HTML from the scrape...\"}",
    "run_at": "2026-09-17T22:20:39.585Z"
  }
}

Field reference

FieldDescription
idInternal ID of this scrape-log entry.
show_typeWhich part of the league system was being scraped, e.g. "teams", "fixtures", "results", "league".
club_idChelmsford's club ID on the league system, or null for a competition-level scrape.
comp_idCompetition ID being scraped, or null if this run wasn't scoped to one competition.
status"success" if the scrape completed normally; other values (e.g. an error status) are possible if a run failed.
messageRaw debug output from the scrape — often a fragment of the HTML the league system returned. It's there for troubleshooting, not meant to be parsed; treat it as an opaque string and don't rely on its exact content or length.
run_atWhen this scrape ran, as an ISO timestamp.

Note this reports on the single most recent scrape run, not necessarily one covering fixtures — check show_type if you specifically care about fixture freshness.

Errors

Errors come back as JSON with a normal HTTP status code:

StatusMeaningExample body
401 Missing or incorrect X-API-Key header. {"error": "Unauthorized"}
429unverified Too many requests in a short space of time — see Rate Limits. {"error": "Too Many Requests"}

Rate Limits

This API runs on a free hosting tier, so there's a limit on how many requests it accepts from any one key or address in a short period. Normal use — a page that refreshes every so often, a script that checks in occasionally — will never come close to it.

If you're building something that needs to call the API very frequently (many times a minute, for lots of users), please email it@chelmsfordsc.org.uk first so we can make sure it'll work smoothly for everyone.

Support

Questions, API key requests, competition IDs, or something not working as documented — email it@chelmsfordsc.org.uk and we'll help out.
